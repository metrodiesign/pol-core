## Lessons Learned

- **Pattern**: raw-SQL port (`SqlQueryRaw`/`FromSqlInterpolated`) ทุกตัวต้องมี integration test ที่เรียก method จริงผ่าน DbContext จริง — test ที่ยิง SQL สำเนามือผ่าน `SqlConnection` ดิบพิสูจน์แค่ว่า "SQL ที่ฉันคิดว่ามันรัน" ใช้ได้ ไม่ใช่ "SQL ที่ EF ประกอบจริง" — **Why**: bug #1 (`Msg 11719` derived table) และ #2 (`Invalid column name 'Amount_Amount'`) escape ทุก gate (build เขียว, unit เขียว, integration เขียว) เพราะไม่มี test ตัวไหนเรียกเส้นจริงผ่าน EF เลย — purchase flow ตายทั้งเส้นบน develop โดยไม่มีอะไรแดง
- **Discovery**: 2C2P sandbox — PromptPay จ่ายจบได้จริงด้วย simulator ทางการ `uatqrgw.2c2p.com/TQRPromptPayTestTools` (upload รูป QR ชื่อไฟล์ต้นฉบับจาก S3 เท่านั้น + payer fields ต้องเติมเองไม่งั้น `resCode 99`) และ payment token ของ hosted page หมดอายุใน ~ไม่กี่ชั่วโมง (`4093`) — **Why**: E2E QR รอบหน้าไม่ต้องหยุดที่ "render แล้ว pending" อีก และต้อง mint session ใหม่ก่อนทดสอบเสมอถ้า session ค้างข้ามครึ่งวัน (รายละเอียดเต็มใน HANDOFF purchase-flow-completion)
