## Lessons Learned

- **Pattern (stack .NET, promoted → `stack/dotnet.md`)**: minimal-API `MapGroup("/x").MapGet("")` (empty root pattern) render RawText เป็น **trailing-slash** `/api/v1/products/` — routing ยอมรับทั้ง slash/no-slash เลย build เขียว + smoke ไม่ 404 = ปิดบัง defect; จับได้เฉพาะ arch test ที่ enumerate `EndpointDataSource`. — **Why**: big-bang route migration ต้อง verify ด้วย arch-guard (route table เทียบ invariant) + complete legacy-404 (generate จาก mapping table ไม่ sample) ไม่ใช่ build/smoke; แก้: map area-root explicit path บน parent group.
- **Discovery (process, ยืนยัน lesson เดิม ไม่ duplicate)**: task-gate hook ที่ block ตอน flip `[x]` — LESSONS.md มี lesson นี้อยู่แล้ว (fix = edit ก้อนเดียวคร่อม checkbox→Evidence bullet แรก). รอบนี้ใช้ "evidence-first แล้วค่อย flip" ซึ่ง **ไม่ช่วย** (hunk ของ flip เป็นบรรทัดเดียว ไม่มี Evidence → block) — ตรงกับที่ lesson เดิมเตือน. — **Why**: ควรทำ combined edit ตาม lesson เดิมตั้งแต่แรก จะไม่เสีย churn 6 รอบ (task 1-6 โดนทุก task).
- **Pattern (spec-sync idempotency)**: GitHub issue/PR แชร์ number sequence เดียวกัน — epic ได้ #50 (ถัดจาก PR #49) แล้ว task ได้ #51-57 เรียง. สร้าง sub-issue **sequential batch ตาม DAG** (dep number ต่ำกว่าเสมอ สร้างก่อน) → `Depends on: #NN` resolve ในรอบเดียวไม่ต้อง second pass; `sub_issue_id` = database `id` (จาก `issue_write` result) ไม่ใช่ issue number. — **Why**: parallel create = number assignment racy, ทำ Depends-on link ผิด.
