## Lessons Learned

- **Pattern**: seed GUID ต้อง **deterministic AND RFC-4122 well-formed** — คงที่ (ไม่ NEWID) พอสำหรับ SQL `uniqueidentifier` แต่ nil version/variant (`…-0000-0000-…`) = malformed UUID (ดูเหมือน placeholder). ตั้ง version nibble = `4` + variant = `8` (`…-4000-8000-…`) คง namespace ต่อตาราง + row counter ได้ (`a1000000-0000-4000-8000-0000000000NN`). `Down` ใช้ `DELETE … WHERE Id LIKE 'a1000000-%'` (implicit convert uniqueidentifier→string ได้, CI collation). — **Why**: user reject nil-variant; well-formed = ไม่ถูก reviewer/tool ตีว่า placeholder + ยังคง deterministic ครบ.
- **Discovery**: source-gen Mediator (martinothamar) ไม่รองรับ **open-generic handler** → CRUD ที่ symmetric N ตาราง อย่าเขียน N×concrete handler (boilerplate ล้วน); ใช้ generic service (`IMasterDataStore<T>` ผ่าน `_db.Set<T>()`) bypass Mediator แต่ **คง commit ผ่าน keyed "admin" UoW** (S2). TPC (`UseTpcMappingStrategy` + abstract base) ให้ FK type-safe 4 ตารางโดยไม่มี discriminator/base table. — **Why**: ตัดสิน code-shape จากข้อจำกัด framework จริง ไม่ใช่รสนิยม.
- **Pattern**: code ใหม่ที่ mirror family เดิม (route group, EF `Like`, SFS, seed) → grep sibling + `.ai/shared/stack/dotnet.md` หา escape/route/tie-breaker pattern ที่มีอยู่ **ก่อนเขียน**. เคสนี้ Codex จับ 2 P2 ที่เป็น convention documented แล้ว: trailing-slash MapGroup+empty-root (dotnet.md L90) และ LIKE ต้อง `SfsLike.Escape`+`Like(,,"\\")` (L80) — ทั้งคู่เขียนซ้ำผิดเพราะไม่ได้เปิด profile ก่อน. — **Why**: reuse up-front ถูกกว่ารอ review round-trip; convention มีแล้วแต่ไม่อ่าน = จ่าย CI/review cycle ฟรี.
