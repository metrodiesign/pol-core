## Lessons Learned

- **Pattern**: GitHub MCP server (`plugin:github:github`) ใน repo นี้ต่อไม่ติด (`claude mcp list` → Failed to
  connect) แม้ skill สั่งให้ใช้ MCP tool เป็นหลัก — fallback `rtk proxy gh <cmd>` ให้ output JSON สะอาดเหมือน MCP
  (RTK hook ไม่มา mangle เพราะ proxy bypass การ rewrite) — **Why**: กันเสียเวลาลอง MCP ซ้ำทุกครั้งที่ sync
  spec ไป GitHub ใน repo นี้; เช็ค `claude mcp list` ก่อนถ้า MCP tool หาไม่เจอใน ToolSearch
- **Pattern**: feature branch ที่ PR merge ไปแล้ว (เช่น `feat/rf2-iam-rbac`) ห้าม commit ต่อ แม้เป็นแค่ sync
  artifact (manifest json) — ต้อง branch ใหม่จาก develop สด + PR แยกเสมอ — **Why**: commit บน branch merged
  แล้วไม่ผูกกับ PR ไหน, push ตรง develop ก็ผิด workflow rule (ห้าม push ตรง main/develop)
