## Lessons Learned

- **Pattern**: bugfix spec ที่ task แรกเป็น repro test (ต้อง RED): อย่า flip `[x]` ของ task test ก่อน fix land — task-gate รัน `SDD_TEST_CMD` ตอน flip แล้วจะ block ที่สถานะแดง. ทำ T-test + T-fix ให้เขียวก่อน แล้ว flip ตามลำดับ โดย capture output RED จริง (ชื่อ test + assertion message) ลง Evidence ของ T-test. — **Why**: ลำดับ TDD ชนกับ gate โดยธรรมชาติ; หลักฐาน repro RED ยังครบโดยไม่ต้องผ่าน gate ที่สถานะแดง.
- **Discovery**: การเขียน reference doc แบบ "target + mark สถานะ as-built" บังคับ verify ทุก claim กับโค้ด → เจอ bug ระดับ P1 ที่ test 20/20 เขียวซ่อนไว้ (path ไม่มี coverage เลย) — **Why**: doc ชนิดนี้ทำหน้าที่ audit ราคาถูก; claim ที่เขียนไม่ได้เพราะโค้ดไม่รองรับ = สัญญาณ gap/bug.
